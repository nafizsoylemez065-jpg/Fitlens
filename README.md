# FitLens 🍽️📸

Fotoğraf çek, yapay zeka kalorisini hesaplasın. Mobil fit yemek takip uygulaması.

## Özellikler
- 📸 Kamera ile yemek fotoğrafı çekme
- 🤖 Mistral vision (Pixtral) ile gerçek AI kalori analizi — API anahtarı yoksa demo modu
- 🎯 Günlük kalori hedefi (Mifflin-St Jeor ile otomatik veya manuel)
- 📊 Makro takibi (protein/karbonhidrat/yağ) ve 7 günlük grafik

## Çalıştırma
`index.html` dosyasını tarayıcıda aç. Kurulum gerekmez.
